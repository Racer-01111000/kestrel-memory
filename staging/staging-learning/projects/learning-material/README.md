# learning-material project

This project is the host-side working area for material that will later be moved to the node.

## Folder roles
- `incoming/` — first landing area for project-bound files
- `sources/` — preserved source material curated for this project
- `notes/` — summaries, extracts, claims, comparisons
- `classified/` — reviewed material split by confidence or purpose
- `handoffs/` — project-specific instructions for the node or future Kestrel
- `exports/` — files or folders copied into final transfer bundles

## Working rule
Move material through the project in stages:
`incoming` → `sources/notes` → `classified` → `exports` → `transfer`

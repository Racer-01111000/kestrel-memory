# PROJECT

Name: learning-material

## Purpose
Stage and organize learning material on the host before offloading curated bundles to the node.

## Scope
This project holds source material, working notes, classification decisions, and transfer-ready outputs related to learning ingestion.

## Rules
- keep raw sources in `sources/`
- keep summaries and extracts in `notes/`
- keep node-facing instructions in `handoffs/`
- do not treat raw source material as canonical truth
- promote only after review and classification

## Current objective
Prepare separated, provenance-aware bundles that can be copied to the node without mixing raw source, interpretation, and trusted knowledge.

# Projects

Use one folder per project.

Suggested shape:

- `projects/<project>/PROJECT.md`
- `projects/<project>/STATE.md`
- `projects/<project>/DECISIONS.md`
- `projects/<project>/TASK_LEDGER.md`
- `projects/<project>/OPEN_QUESTIONS.md`
- `projects/<project>/sources/`
- `projects/<project>/notes/`
- `projects/<project>/handoffs/`

Project folders are for material bound to one mission or topic.
Cross-project truths belong in `knowledge/`, not here.

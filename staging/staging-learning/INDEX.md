# Staging Learning Index

## Start here
- `README.md` — overall purpose and structure
- `runtime/ACTIVE_CONTEXT.md` — current staging state
- `projects/learning-material/README.md` — project workflow
- `transfer/learning-material-2026-04-13/README.md` — first ready transfer bundle

## Operational path
1. drop files into `dropbox/raw/` or `projects/learning-material/incoming/`
2. split source material from notes
3. classify what matters
4. export project-ready files
5. place node-ready output in `transfer/learning-material-2026-04-13/`
6. offload to node when connected

## Anti-chaos rules
- raw source is not canonical
- notes are not facts by default
- disputed material stays disputed
- transfer bundles should be self-explaining
